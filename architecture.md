# Архитектура приложения "Наследие: Твоя История"

Это приложение предназначено для создания глубоких, персонализированных мемуаров. Оно объединяет человеческие воспоминания с мощью ИИ для создания качественного литературного продукта.

## 1. Технологический Стек

### Frontend (React + Vite)
- **State Management**: React Context API (для простых данных) + React Query (для работы с БД).
- **Styling**: Vanilla CSS с современными CSS Variables (темы "Классика", "Современный", "Архив").
- **Animations**: Framer Motion для плавных переходов между вопросами.
- **Localization**: `i18next` для поддержки языков (RU, EN, KZ и др.).
- **PDF Rendering**: `react-pdf/renderer` для генерации превью и финального файла прямо в браузере.

### Backend & AI (Python/Functions)
- **AI Editor**: Firebase Functions (Python) + OpenAI API (модель GPT-4o).
  - *Логика*: ИИ анализирует ответ, исправляет ошибки, улучшает структуру, но сохраняет "голос" автора.
- **Storage**: Firebase Storage для хранения фото в оригинальном качестве.
- **Database**: Firestore для хранения структуры книги и ответов.

## 2. Модель Данных (Firestore)

### `users` (Коллекция)
- `uid`: string (Firebase Auth ID)
- `settings`: { preferredLanguage: string, theme: string }

### `books` (Коллекция)
- `id`: string
- `ownerId`: string
- `title`: string
- `authorName`: string
- `createdAt`: timestamp
- `status`: "draft" | "editing" | "ready"

### `chapters` (Подколлекция в `books`)
- `id`: string
- `title`: string
- `order`: number
- `questions`: [
    {
      "id": "q1",
      "text": "...",
      "answer": "...",
      "aiEditedAnswer": "...",
      "photos": ["url1", "url2"],
      "status": "answered" | "reviewed"
    }
  ]

## 3. Функциональные Модули

### A. Модуль "Интервьюер"
Интерфейс в стиле чата или пошаговой формы. 200 вопросов разбиты на 10 глав (от детства до мудрости). Поддерживается сохранение черновиков.

### B. Модуль "AI Редактор"
После того как пользователь закончил главу, он может нажать кнопку "Улучшить". ИИ:
1. Исправляет опечатки.
2. Соединяет разрозненные предложения в связный рассказ.
3. Добавляет художественные описания (опционально).

### C. Модуль "Верстка и Фото"
Пользователь может загружать фото к каждому ответу. В режиме предпросмотра можно менять макет страницы (фото слева/справа/на весь лист).

### D. Модуль "Печатная Книга"
Экспорт в PDF с учетом полей для переплета. Поддержка разных форматов (A4, A5).

## 4. План Разработки

1.  **Этап 1: Фундамент (Текущий)**: Настройка Firebase, Auth, базовый UI.
2.  **Этап 2: Контент**: Загрузка всех 200 вопросов в базу.
3.  **Этап 3: Редактор**: Реализация интерфейса ответов и загрузки фото.
4.  **Этап 4: Интеграция ИИ**: Подключение OpenAI через Cloud Functions.
5.  **Этап 5: Печать**: Создание движка генерации PDF.
